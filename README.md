# 小学数学辅导老师（Primary Math Tutor）

一个面向小学数学学习的 AI 互动教学开源项目。

## 项目介绍

本项目致力于通过 AI 辅助讲解和动态数学可视化，帮助学生理解数学题目、掌握解题思路。

项目重点：

- 原题保真：保留上传题目中的文字、图形和几何信息。
- 图片选题：支持从整张试卷中选择单道题目。
- 分步讲解：按照读题、分析、列式、计算、验算的教学思路组织讲解。
- 互动黑板：探索动态板书和可交互的数学模型。
- AI 接口：计划支持 DeepSeek 等可配置的 AI 服务。
- 多端适配：面向 Windows 电脑和手机浏览器。
